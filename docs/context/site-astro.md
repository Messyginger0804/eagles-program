# Site: Astro build, pages, styling

Static fan-edition game-day program (Wilmer-Hutchins Eagles). Astro 7, `output: 'static'`, `trailingSlash: 'always'`, `base: '/'`; `site` is the custom domain (see `astro.config.mjs`). TypeScript extends `astro/tsconfigs/strict` (`tsconfig.json`).

## Layout of src/
- `src/pages/`: `index`, `schedule`, `roster`, `stats`, `matchup`, `more`, `seniors-coaches`, `print` (booklet order), `games/[id].astro`, `players/[slug].astro` (both use `getStaticPaths`), and `manifest.webmanifest.ts` (PWA manifest endpoint).
- `src/layouts/Program.astro`: the single layout. Head, fonts, bottom tab bar, number sheet, welcome sheet, footer. `/print` gets the `no-art` class (no background art, no welcome sheet).
- `src/components/`: EventCard, GameCard, GameRow, Logo, NumberSheet (jersey lookup), BoxScore (per-game player stat tables on `games/[id]`, with a null-stats message), PbpTouchdowns, RosterTable, StatCaveat, StatsSource (MaxPreps-upload notice, `plain` prop for print; shown on stats, game box score, player, seniors, print), WelcomeSheet.
- `src/lib/`: `data.ts` (loader used by pages), `db.ts`, `schema.ts` (zod), plus pure helpers `season.ts`, `format.ts`, `statcards.ts`, `numbers.ts`, `url.ts`. See `data-db.md`.
- `src/config.ts`: site title, tagline, theme color, `INDEXABLE` (false, so pages emit noindex), welcome note, and the builder promo (`PROMO.enabled`).

## Base path and URLs
Internal links and assets go through `withBase()` in `src/lib/url.ts`. It adds the base and a trailing slash to page paths, and leaves paths with a file extension alone. Gotcha: `src/styles/global.css` hardcodes root paths like `/art/...` in `url()`, which only works because base is `/`. If base ever changes, update the CSS. `scripts/check-links.ts` also hardcodes `BASE = '/'`.

## Styling
Plain CSS, no framework: `src/styles/global.css` (CSS variables for the dark navy/royal theme, fonts Anton/Oswald/Source Sans 3 from `@fontsource`) and `src/styles/print.css` (loaded with `media="print"`). Native view transitions morph the jersey number between lists and player pages (inline script in `Program.astro`).

## Poster art (2026 schedule poster restyle)
- Assets in `public/art/`: `eyes-*` (header band), `storm-*` (footer), `helmet-*` (player page hero), each as avif and webp at several widths. Team logos/icons in `public/brand/`.
- Applied in `global.css` via `body::before` (eyes), `.site-footer::before` (storm) and `.phero::after` (helmet), with `image-set()` avif/webp. 1x phones under 700px use `eyes-640`.
- Generated by `scripts/make-art.mjs` from the poster file (not in the repo). Only text-free crops are kept; never commit the full poster.

## External assets
- The schedule page hotlinks a GIPHY Jim Mora "Playoffs?!" clip (`PLAYOFFS_GIF` in `src/config.ts`) in a `.pogif` card, only when a game has `playoff: true`; reduced-motion users get the still. No CSP or host headers exist (GitHub Pages), so nothing blocks it.
