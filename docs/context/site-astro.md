# Site: Astro build, pages, styling

Static fan-edition game-day program (Wilmer-Hutchins Eagles). Astro 7, `output: 'static'`, `trailingSlash: 'always'`, `base: '/'`; `site` is the custom domain (see `astro.config.mjs`). TypeScript extends `astro/tsconfigs/strict` (`tsconfig.json`).

## Layout of src/
- `src/pages/`: `index`, `schedule`, `roster`, `stats`, `matchup`, `more`, `seniors-coaches`, `print` (booklet order), `games/[id].astro`, `players/[slug].astro` (both use `getStaticPaths`), and `manifest.webmanifest.ts` (PWA manifest endpoint).
- `src/layouts/Program.astro`: the single layout. Head, fonts, bottom tab bar, number sheet, welcome sheet, footer. `/print` gets the `no-art` class (no background art, no welcome sheet).
- `src/components/`: EventCard, GameCard, GameRow, Logo, NumberSheet (jersey lookup), BoxScore (per-game player stat tables on `games/[id]`, with a null-stats message), PbpTouchdowns, RosterTable, StatCaveat, StatsSource (MaxPreps-upload notice, `plain` prop for print; shown on stats, game box score, player, seniors, print), WelcomeSheet, EagleAlert.
- `src/lib/`: `data.ts` (loader used by pages), `db.ts`, `schema.ts` (zod), plus pure helpers `season.ts`, `format.ts`, `mascot.ts`, `statcards.ts`, `numbers.ts`, `url.ts`. See `data-db.md`.
- `src/config.ts`: site title, tagline, theme color, `INDEXABLE` (false, so pages emit noindex), welcome note, and the builder promo (`PROMO.enabled`).
- `/fix-a-name/` (`src/pages/fix-a-name.astro`, pure helpers in `src/lib/fixName.ts`) is a no-JS-capable form that POSTs to `FORMS_ENDPOINT` in `src/config.ts` (receiver: repo DFW-Software-Consulting/hutch-forms at forms.dfwsc.com); linked from the footer, More and player pages. JS uses fetch JSON; no-JS gets a 303 back with `?sent=1#sent`, `?error=rate_limited#rate-limited` or `?error=<code>#error`; three `.fn-notice` paragraphs (ids `sent`, `rate-limited`, `error`) show via CSS `:target`, and the JS removes them and uses `#fn-status` instead.

## Eagle-on-Eagle alert
`EagleAlert.astro` (rendered from `Program.astro`, not on `/print`) is a `.sheet` dialog that renders at build time only when `isMascotMirror(getNextGame(), team.mascot)` (`src/lib/mascot.ts`) is true: the next game is not final and the opponent mascot equals ours (trimmed, case-insensitive; blank never matches). Copy is `EAGLE_ALERT` in `src/config.ts`. No JS = never opens. Dismissal (Esc, X, Got it, backdrop) is stored per game in localStorage `wh-eagle-alert-dismissed-v1:<game id>`. It waits for the welcome sheet (opens after it closes) and skips if the number sheet is open. The info line shows round, date, kickoff time (when `kickoffTime` is set) and venue.

## Kickoff time and matchup leaders
Game kickoff comes from `games.kickoff_time` via `kickoffLabel()` (`format.ts`): index next-game card, schedule cards/rows, game page, matchup Kickoff fact, print and the alert; "Kickoff TBA" when null. `matchup.astro` renders a "<Opponent> Leaders" table (top passer, rusher, receiver, tackler, sacks for both teams; `LEADER_STATS` in `season.ts`) only when the next opponent has `seasonStats`; otherwise nothing.

## Base path and URLs
Internal links and assets go through `withBase()` in `src/lib/url.ts`. It adds the base and a trailing slash to page paths, and leaves paths with a file extension alone. Gotcha: `src/styles/global.css` hardcodes root paths like `/art/...` in `url()`, which only works because base is `/`. If base ever changes, update the CSS. `scripts/check-links.ts` also hardcodes `BASE = '/'`.

## Styling
Plain CSS, no framework: `src/styles/global.css` (CSS variables for the dark navy/royal theme, fonts Anton/Oswald/Source Sans 3 from `@fontsource`) and `src/styles/print.css` (loaded with `media="print"`). Native view transitions morph the jersey number between lists and player pages (inline script in `Program.astro`).

## Poster art (2026 schedule poster restyle)
- Assets in `public/art/`: `eyes-*` (header band), `storm-*` (footer), `helmet-*` (player page hero), each as avif and webp at several widths. Team logos/icons in `public/brand/`.
- Applied in `global.css` via `body::before` (eyes), `.site-footer::before` (storm) and `.phero::after` (helmet), with `image-set()` avif/webp. 1x phones under 700px use `eyes-640`.
- Generated by `scripts/make-art.mjs` from the poster file (not in the repo). Only text-free crops are kept; never commit the full poster.

## External assets
- The schedule page hotlinks a GIPHY Jim Mora "Playoffs?!" clip (`PLAYOFFS_GIF` in `src/config.ts`) in a `.pogif` card, only when a game has `playoff: true`; reduced-motion users get the still. Both use GIPHY's 200px renditions (`200.webp` 155KB, `200_s.gif` 26KB instead of the 480px 402KB/96KB) because the card renders at most 240px wide. The same page adds muted dashed placeholder rows for the remaining playoff rounds and a games-left line ("5 games to a state title", singular-safe) in that card; the GIPHY credit is plain text, not a link; the round list is `PLAYOFF_ROUNDS` in `src/config.ts` (keyed by season, with UIL source URLs in its comment) and must be updated each season. Logic is in `src/lib/playoffs.ts`. No CSP or host headers exist (GitHub Pages), so nothing blocks it.

## Phone rules
Tap targets: the 44px / padded link rules (opponent, StatsSource links, `td > a` block links, footer and back links) live inside `@media (pointer: coarse), (max-width: 430px)` so desktop keeps the compact pre-phone layout. Keep text at 12px or more. Below 360px `.gcard` result column shrinks so opponent names are not covered. `.gcard.gcard--tbd` needs the extra class to beat the 360px `.gcard` columns.

Box score tables (`BoxScore.astro`) render `<span class="nm-full">Full Name</span><span class="nm-short" aria-hidden="true">F. Last</span>` inside the link (`shortName()` in `format.ts`); no `title`/`aria-label`, so the accessible name is the full name. At 430px and under `.nm-full` is hidden with the sr-only pattern (not display:none) and `.nm-short` shows; above that `.nm-short` is display:none. `.table-scroll` has a CSS-only scroll-shadow hint (`background-attachment: local`) as a progressive enhancement; do not add `-webkit-overflow-scrolling` (it breaks it on iOS).

Playoff rounds: `playoffOutlook` normalizes round names (case, NBSP, parentheticals, "-", trailing "round", `ROUND_ALIASES` such as "State Final") and counts rounds accounted for as max(furthest matched round + 1, playoff game count). A final playoff game with a null result is unknown (consumes its round, not eliminated/champion); `check:stats` warns about it.
